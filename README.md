# Solar-Thermal Direct Air Carbon Capture

This repository provides the open-source **data, modeling code, and plotting/visualization code** supporting the following paper:

> Zhiyuan Fan and Bolun Xu, **“Design Optimization and Global Impact Assessment of Solar-Thermal Direct Air Carbon Capture,”** *Environmental Science & Technology*, 2026.
> DOI: [10.1021/acs.est.6c01034](https://doi.org/10.1021/acs.est.6c01034)

The repository contains the materials used for system design optimization, global impact assessment, and reproduction of the figures and results reported in the paper.
